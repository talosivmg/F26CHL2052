# CSCS 1240 Challenge Level 2052: Temperature Converter

## Challenge
This Python Script reads a value from a file named challenge.data. The value representing the input is converted from Fahrenheit to Celsius or Celsius to Fahrenheit based on a CLI argument of `FtoC` or `CtoF` when running the script. 

## Requitements & Constraints
* **Input File** 'challeng.data' (assume numerical value)
* **Output File** 'challeng.out' (store the converted value)
* **Allowed import** 'sys'       ( sys argument )
* **Allowed builtins** 'open, float' (open file and float integer)
* **User defined functions** 'none'  (only use current reviewed functions)

## How to run
py chl2052.py FtoC
py chl2052.py CtoF
